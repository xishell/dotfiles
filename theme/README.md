# theme

One palette (`palette.toml`, currently **Oxocarbon**: oxocarbon ground, cyberdream accents) → every themed config, generated by `ember-gen` (Rust, `gen/`).

```sh
$EDITOR theme/palette.toml
theme/ember           # build, regenerate, restow, re-render wallpaper if needed
theme/ember --check   # fail if any output drifted from its template
```

- Never hand-edit hex in a generated file: edit the palette or `templates/`.
- Generated files are committed, so plain `stow` works without Rust.

```
theme/
├── palette.toml   [meta] [colors] [ansi] [check] [wallpaper]
├── targets.toml   template → output
├── templates/     one per consumer, by tool
├── wallpaper/     gen.py (wallpaper renderer)
├── gen/           ember-gen
└── ember          wrapper
```

Consumers: bat, btop, claude, git (delta), gtk, hypr (borders, hyprlock), ironbar, kitty, lazygit, mako, mangohud, nvim, qt6ct, ember-bar, swayosd, walker, zsh (prompt, fzf).

## Tokens

| Token | Use |
|---|---|
| `crust` `base` `surface` `selection` `overlay` | backgrounds, darkest → lightest |
| `comment` `fg_dim` `fg` | text, dimmest → brightest |
| `primary` | focus solids: active ws, selection, matches |
| `orange` (pink) / `magenta` (purple) | numbers / keywords; gradient border ends |
| `red` `urgent_bg` `yellow` `green` `teal` `cyan` `blue` | status + syntax |
| `color0`–`color15` | ANSI |

Token names are roles, not hues: `orange` is pink in this palette.

## Filters

| Placeholder | Output |
|---|---|
| `{{ orange }}` / `\| hex` | `#ff7eb6` |
| `\| bare` | `ff7eb6` |
| `\| hexa:f2` | `#ff7eb6f2` |
| `\| rgb` | `255, 126, 182` |
| `\| rgba:0.4` | `rgba(255, 126, 182, 0.4)` |
| `\| hypr` / `\| hypr:ee` | `rgb(ff7eb6)` / `rgba(ff7eb6ee)` |
| `\| mix:base:0.2` | token laid over `base` at 20 % |
| `{{ meta.name }}` | string from `[meta]` |

## Accent check

`[check]`: every listed accent must reach `min_contrast` (WCAG) and `min_chroma` (CIE LCh(uv)) against `against`. On failure nothing is written.

## Targets

```toml
[[target]]
template = "hypr/palette.lua"                      # under templates/
output   = "hypr/.config/hypr/modules/palette.lua" # repo-relative
comment  = "--"                                    # header prefix; "" = no header (JSON)
region   = false                                   # true: only replace ember:begin … ember:end
```

`region = true` suits hand-written files with a small colour block (`tab_bar.py`, `ember-bar`).
