# Neovim Keymaps Cheat Sheet

## Global
### Insert mode

| Key | Action |
|-----|--------|
| `<A-j>` | Move Down |
| `<A-k>` | Move Up |

### Normal mode

| Key | Action |
|-----|--------|
| `<A-j>` | Move Down |
| `<A-k>` | Move Up |
| `<C-h>` | Go to Left Window |
| `<C-j>` | Go to Lower Window |
| `<C-k>` | Go to Upper Window |
| `<C-l>` | Go to Right Window |
| `<Down>` | Down |
| `<S-h>` | Prev Buffer |
| `<S-l>` | Next Buffer |
| `<Up>` | Up |
| `<leader><tab><tab>` | New Tab |
| `<leader><tab>[` | Previous Tab |
| `<leader><tab>]` | Next Tab |
| `<leader><tab>d` | Close Tab |
| `<leader><tab>f` | First Tab |
| `<leader><tab>l` | Last Tab |
| `<leader><tab>o` | Close Other Tabs |
| `<leader>`` | Switch to Other Buffer |
| `<leader>bD` | Delete Buffer and Window |
| `<leader>bb` | Switch to Other Buffer |
| `<leader>qq` | Quit All |
| `N` | Prev Search Result |
| `[b` | Prev Buffer |
| `]b` | Next Buffer |
| `gcO` | Add Comment Above |
| `gco` | Add Comment Below |
| `j` | Down |
| `k` | Up |
| `n` | Next Search Result |

### Operator mode

| Key | Action |
|-----|--------|
| `N` | Prev Search Result |
| `n` | Next Search Result |

### Visual mode

| Key | Action |
|-----|--------|
| `<Down>` | Down |
| `<Up>` | Up |
| `N` | Prev Search Result |
| `j` | Down |
| `k` | Up |
| `n` | Next Search Result |


## LSP (buffer-local)
### Normal mode

| Key | Action |
|-----|--------|
| `<leader>ca` | CodeAction |
| `<leader>cr` | Rename |
| `<leader>q` | Open diagnostics list |
| `K` | HoverDocumentation |
| `[d` | Prev diagnostic |
| `]d` | Next diagnostic |
| `cr` | Rename |
| `gD` | GotoDeclaration |
| `gI` | IncomingCalls |
| `gO` | OutgoingCalls |
| `gd` | GotoDefinition |
| `gi` | GotoImplementation |
| `gl` | Float diagnostic |
| `go` | GotoTypeDefinition |
| `gr` | GotoReferences |
| `gs` | SignatureHelp |
