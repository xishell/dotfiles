# 🚀 Daily Git Plugin Cheat Sheet (OMZP::git)

A **condensed list** of the ~20 most useful git aliases for day-to-day work.

---

## 🔑 Core

- `g` → `git`
- `grt` → cd to repo root
- `gst` → status
- `gss` → short status

---

## ➕ Add & Commit

- `ga` → add
- `gaa` → add all
- `gcmsg "msg"` → commit with message
- `gcam "msg"` → commit all with message
- `gc!` → amend last commit
- `gwip` → WIP commit
- `gunwip` → undo WIP

---

## 🌿 Branch & Switch

- `gb` → list branches
- `gbd` → delete branch
- `gco <br>` → checkout
- `gcb <br>` → new branch
- `gcm` → checkout main
- `gcd` → checkout develop

---

## 🔄 Pull & Push

- `gl` → pull
- `gpr` → pull --rebase
- `gp` → push
- `gpsup` → push + set upstream
- `gpf` → force push (safe lease)

---

## 📊 Log & Diff

- `glg` → log with stats
- `glol` → pretty log
- `glo` → oneline log
- `gd` → diff
- `gds` → diff staged

---

✅ With just these, you can handle 90% of daily Git work efficiently.
